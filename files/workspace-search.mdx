The Search sidebar scans every file in your workspace for a text pattern and shows results grouped by file with line previews. You can jump to any match in one click, or replace matches one at a time, per file, or all at once across the entire project.

## Open the Search Sidebar

| Action | Shortcut / Menu |
|---|---|
| Toggle Search sidebar | `Ctrl+Shift+F` |
| Open via menu | **View → Search** or **Edit → Find in Files** |

## Find Text Across Files

<Steps>
  <Step title="Type your query">
    Enter a search term in the **Search** input. Results appear grouped by filename as you type, each with a line preview.
  </Step>
  <Step title="Click a result">
    Clicking any result opens the file and moves the cursor directly to that line.
  </Step>
</Steps>

<Note>
`node_modules` and other common generated folders are excluded from search results by default. You can add your own exclude patterns in the search options.
</Note>

## Replace Text Across Files

<Steps>
  <Step title="Open the Replace field">
    Press `Ctrl+H` or click the arrow next to the search input to expand the **Replace** field.
  </Step>
  <Step title="Enter your strings">
    Type the text to find in the top field and the replacement in the bottom field.
  </Step>
  <Step title="Review and replace">
    Use the inline controls to **replace one match at a time**, **replace all in a file**, or **replace all in the workspace**. Changes are written to disk immediately.
  </Step>
</Steps>

<Warning>
Replace All in Workspace modifies every matching file on disk. Review your matches carefully before using it, and make sure you have no uncommitted changes you'd like to preserve.
</Warning>

## Search Options

Toggle these options using the icons in the search input row:

| Option | What it does |
|---|---|
| **Match Case** (`Aa`) | Treats uppercase and lowercase as different characters |
| **Match Whole Word** (`ab`) | Only matches the exact word, not substrings |
| **Use Regular Expression** (`.*`) | Enables regex patterns; use capture groups like `$1` in the replace field |

## Choosing the Right Search Tool

Shape offers several search tools for different goals:

| Feature | Shortcut | Scope |
|---|---|---|
| **Go to File** | `Ctrl+P` | Filenames only |
| **Find in Files** | `Ctrl+Shift+F` | File contents |
| **Workspace Symbols** | `Ctrl+T` | Functions, classes, variables |

<Tip>
Use `Ctrl+T` (workspace symbols) when you know the name of a function or class but not which file it lives in — it's faster than a full-text search for identifiers.
</Tip>
