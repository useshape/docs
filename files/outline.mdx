The Outline sidebar gives you a structural map of whatever file you're currently editing. Instead of scrolling through hundreds of lines, click any symbol in the Outline to move your cursor there instantly.

## Open the Outline

Click the **list icon** on the activity bar, or go to **View → Outline** in the menu. The Outline updates automatically as you switch between editor tabs — it always reflects the active file.

## What the Outline Shows

The symbols that appear depend on the language of the active file:

| Language | Symbols shown |
|---|---|
| TypeScript / JavaScript | Functions, classes, interfaces, variables |
| CSS | Rules and selectors |
| HTML | Elements and sections |
| Markdown | Headings (all levels) |

## Jump to a Symbol

Click any entry in the Outline list. Shape moves the cursor to that symbol's definition and scrolls the editor to bring it into view.

<Tip>
The Outline is especially useful in long files. Use it to hop between methods in a large class without losing your place.
</Tip>

## Symbols Not Appearing?

If the Outline is empty or missing entries, check two things:

<Steps>
  <Step title="Verify the language mode">
    Look at the language indicator in the bottom-right corner of the editor. If it shows **Plain Text** or the wrong language, click it and select the correct one.
  </Step>
  <Step title="Check LSP is enabled">
    Open **Settings → Lint and LSP** and confirm that language server support is active for your file type. The Outline depends on the language server to extract symbols.
  </Step>
</Steps>

## Outline vs. Other Navigation Tools

| Tool | Scope | Best for |
|---|---|---|
| **Outline sidebar** | Active file only | Navigating structure inside one file |
| **Breadcrumbs** (titlebar) | File path | Seeing where you are in the file hierarchy |
| **Workspace Symbols** (`Ctrl+T`) | Entire project | Finding a function or class across all files |

<Note>
For project-wide symbol search, use `Ctrl+T`. The Outline only shows symbols in the file you're currently editing.
</Note>
