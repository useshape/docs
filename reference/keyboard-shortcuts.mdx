Shape inherits the keyboard model of Monaco / VS Code and adds its own shortcuts for AI Chat, visual design, and Git. All shortcuts use **Ctrl** as the primary modifier on Windows. Use the Command Palette (**Ctrl+Shift+P**) to search for any action by name — the assigned shortcut is displayed on the right side of each result.

## File and Workspace

| Action | Shortcut |
|---|---|
| New Text File | **Ctrl+N** |
| New Window | **Ctrl+Shift+N** |
| Open File | **Ctrl+O** |
| Open Folder | **Ctrl+K** then **Ctrl+O** |
| Close Folder | **Ctrl+K** then **Ctrl+W** |
| Save | **Ctrl+S** |
| Save As | **Ctrl+Shift+S** |
| Save All | **Ctrl+K** then **S** |
| Close Tab | **Ctrl+W** |
| Close All Tabs | **Ctrl+K** then **E** |
| Recent Files | **Ctrl+E** |
| Close Window | **Alt+F4** |

## Chord Shortcuts (Two-Step)

Chord shortcuts require pressing a first key combination, releasing it, then pressing the second key within a short window.

| Action | Chord |
|---|---|
| Open Folder | **Ctrl+K**, then **Ctrl+O** |
| Close Folder | **Ctrl+K**, then **Ctrl+W** |
| Save All | **Ctrl+K**, then **S** |
| Close All Tabs | **Ctrl+K**, then **E** |
| Format Selection | **Ctrl+K**, then **Ctrl+F** |
| Zen Mode | **Ctrl+K**, then **Z** |
| Fold All | **Ctrl+K**, then **Ctrl+0** |
| Unfold All | **Ctrl+K**, then **Ctrl+J** |

## Palette-Only Commands

These actions have no default keyboard shortcut. Run them by opening the Command Palette (**Ctrl+Shift+P**) and typing the command name.

- **View: Show Problems**
- **View: Show Output**
- **Editor: Toggle Minimap**
- **Editor: Toggle Inlay Hints**
- **Chat: Show History**
- **Change Language Mode…**
- **View: Toggle Zen Mode**
- **Join Lines**
- **Transform to Uppercase**
- **Transform to Lowercase**

<Tip>
  To discover any action's shortcut, press **Ctrl+Shift+P** and start typing. The shortcut — or the note *"not bound"* — appears to the right of every result.
</Tip>
