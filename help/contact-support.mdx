The Shape team offers support through a contact form, direct email, and a dedicated security disclosure process. Choose the channel that fits your question.

## Contact Form

Use the contact form at [useshape.org/contact](https://useshape.org/contact) for:

- Billing and subscription questions
- Account access problems
- General product questions
- Security disclosures (select **Security** as the topic)

### What to Include

To help the team respond quickly, include the following in every request:

| Detail | Where to find it |
|---|---|
| **Account email** | The email address you signed in with |
| **Operating system** | Windows version (e.g. Windows 11 23H2) |
| **Shape version** | **Help → About** in the title bar menu |
| **Error code** | If applicable — see [Error Codes](/help/errors) |
| **Steps to reproduce** | A brief description of what you did and what happened |

<Warning>
  Never include your password, payment card numbers, or AI API keys in a support request. The Shape team will never ask for these.
</Warning>

## Email

Send questions about billing, your account, or Cloud AI usage directly to:

**[hello@useshape.org](mailto:hello@useshape.org)**

Include the same details listed above so the team can look up your account and respond without needing a follow-up.

## Security Disclosures

If you have discovered a security vulnerability in Shape, please report it privately:

- **Preferred:** Use the contact form at [useshape.org/contact](https://useshape.org/contact) and set the topic to **Security**.
- **Alternative:** Follow the instructions in `SECURITY.md` in the Shape GitHub repository.

<Note>
  Please do not file public GitHub issues for security vulnerabilities. Private disclosure gives the team time to investigate and release a fix before the issue is publicly known.
</Note>
