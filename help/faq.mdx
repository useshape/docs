Find answers to the most common questions about Shape IDE below. If your question is not listed here, reach out via the [contact page](https://useshape.org/contact) or email [hello@useshape.org](mailto:hello@useshape.org).

<Accordion title="Is Shape free?">
  Yes. Shape is free to download and use. The free tier includes access to the **Auto** AI model.

  Paid plans unlock additional AI models and higher usage credits. Visit the [Pricing page](https://useshape.org) for a full comparison.
</Accordion>

<Accordion title="Where is my data stored?">
  All editing — your files, Git history, and project data — stays local on your machine. Shape never uploads your source code.

  When you use AI Chat features while signed in, the messages you send are processed by Shape's cloud AI infrastructure to generate responses. Shape does not retain your code for training purposes.
</Accordion>

<Accordion title="How do credits work?">
  Credits are consumed when you use paid AI models in AI Chat. Each request deducts a number of credits based on the model and the size of the exchange.

  Check your remaining credits in any of these places:

  - **Settings → Account → Usage**
  - The **avatar menu** in the Shape title bar
  - Your account dashboard at [useshape.org](https://useshape.org)
</Accordion>

<Accordion title="Can I use Shape offline?">
  Yes, for everything that does not require the cloud. The code editor, terminal, Git panel, file management, and all local language tooling (ESLint, Prettier, language servers) work fully offline.

  AI Chat requires a network connection and an active Shape account session. Plan and Code modes will not function without connectivity.
</Accordion>

<Accordion title="What license does Shape use?">

</Accordion>

<Accordion title="Can I inspect and edit a live web page?">
  Yes. Open the **Browser** tab (Chrome icon on the Activity Bar, or **View → Preview**), navigate to your local development URL, and press **Ctrl+Shift+D** to enter design mode.

  In design mode, click any element on the page to inspect it. Use the **Apply** action to write the design change back to your source file.
</Accordion>

<Accordion title="Can I review pull requests in Shape?">
  Yes. Open **Window → Git Manager** after signing in with your GitHub account. Git Manager shows open pull requests for any repository whose remote is hosted on `github.com`. You can review diffs, leave comments, and manage PR status without leaving Shape.
</Accordion>
