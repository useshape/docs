Shape's integrated terminal is a full shell session that opens directly in your project root — no need to switch windows or manually navigate to your folder. Run build commands, manage dependencies, use Git from the command line, and keep everything in one place.

## Open the Terminal

| Method | Action |
|--------|--------|
| **Toggle panel** | Press **Ctrl+`** |
| **New terminal tab** | Press **Ctrl+Shift+`** |
| **Menu** | **View → Terminal** or **Terminal → New Terminal** |
| **Titlebar button** | Click the panel toggle in the titlebar |

Hiding the panel with **Ctrl+`** does not close your terminal sessions — all open tabs resume exactly where you left them when you reopen the panel.

## Choose Your Shell

Go to **Settings → Features → Terminal → Default Shell** to set which shell new terminal tabs use:

| Option | Shell |
|--------|-------|
| **Auto** | Windows system default |
| **PowerShell** | Windows PowerShell |
| **Command Prompt** | `cmd.exe` |
| **Git Bash** | Bash via Git for Windows |

After changing the setting, open a **new terminal tab** — existing sessions continue using the shell they were started with.

## Work with Multiple Tabs

Each terminal tab is an independent shell session with its own process, history, and working directory.

<Steps>
  <Step title="Open a new tab">
    Click the **`+` button** on the terminal tab bar, or press **Ctrl+Shift+`**.
  </Step>
  <Step title="Switch between tabs">
    Click any tab in the terminal tab bar to bring it into focus.
  </Step>
  <Step title="Close a tab">
    Right-click the tab and choose **Close**, or go to **Terminal → Kill Current Terminal**.
  </Step>
</Steps>

<Note>
Closing the terminal panel does not kill your running sessions. The next time you open the panel, all tabs are still active.
</Note>

## Working Directory

New terminal tabs open in the root of your currently open project folder. If no folder is open, Shape prompts you to open one before starting a session.

## Copy and Scrollback

- **Copy text** — select any text in the terminal; it copies automatically if **Copy on Select** is enabled in Terminal Settings. Otherwise, use **Ctrl+C** after selecting.
- **Scrollback buffer** — configure the number of lines retained in **Terminal Settings**. Increase it when working with verbose build output you need to scroll back through.

## AI-Suggested Terminal Commands

When the AI chat proposes a terminal command as part of a task, approving it runs the command directly in the integrated terminal. Output appears in the same panel, so you can review results and continue the conversation without leaving the IDE.
