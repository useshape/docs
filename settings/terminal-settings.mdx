Shape's integrated terminal settings are found under **Settings → Features → Terminal**. You can change your default shell, adjust the terminal font independently from the editor, control how much output history is retained, and tweak selection behavior.

## Default Shell

Choose which shell Shape launches when you open a new terminal tab:

| Option | Description |
|---|---|
| **Auto** | Uses your Windows system default shell. |
| **PowerShell** | Launches PowerShell (or PowerShell 7 if installed). |
| **Command Prompt** | Launches `cmd.exe`. |
| **Git Bash** | Launches the Bash shell bundled with Git for Windows. |

<Note>
  Changing the default shell does not affect any terminal tabs that are already open. Press **Ctrl+Shift+`** to open a new terminal tab that uses the updated shell.
</Note>

## Terminal Font

The terminal uses its own font settings, independent from the editor font you set under **Settings → Editor**.

| Setting | Description |
|---|---|
| **Font family** | The typeface used in the terminal. Choose a monospace font for correct character alignment. |
| **Font size** | Size in pixels for terminal text. |

## Scrollback Buffer

The scrollback setting controls how many lines of past output the terminal retains in memory. Scroll up in a terminal tab to read older output.

<Accordion title="Choosing a scrollback size">
  Higher values let you review more history — useful when running long builds or test suites — but consume more memory. Lower values keep memory usage minimal if you have many terminal tabs open simultaneously. Shape offers several presets ranging from a few thousand lines up to much larger buffers. Choose based on how far back you typically need to scroll.
</Accordion>

## Copy on Select

| State | Behavior |
|---|---|
| **Enabled** | Any text you highlight in the terminal is copied to the clipboard immediately. |
| **Disabled** | Text is only copied when you explicitly press **Ctrl+C** after selecting it. |

<Tip>
  If you frequently use **Ctrl+C** to interrupt running processes, keep Copy on Select **disabled** to avoid accidentally overwriting your clipboard.
</Tip>

## Environment Variables

The terminal inherits your system `PATH` and all user environment variables from Windows. If you install a new tool at the OS level (for example, a new Node.js version or a CLI utility), restart Shape or open a new terminal tab for the updated `PATH` to take effect.

<Note>
  Shape does not modify your system environment variables. Configure environment variables in Windows System Properties or a shell profile (`.bashrc`, PowerShell profile) and they will be available in Shape's terminal.
</Note>
