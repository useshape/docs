Shape stores all your preferences in a dedicated settings editor. Most changes take effect immediately; a few apply the next time you perform the relevant action, such as opening a new terminal tab after changing your default shell.

## Open Settings

Open the settings editor in any of these ways:

- Click the **gear icon** on the Activity Bar (bottom-left)
- Select **Settings** in the title bar menu
- Go to **Window → Settings**
- Press **Ctrl+,**

Close the settings editor with **Ctrl+W**.

## Key Setting Groups at a Glance

<Tabs>
  <Tab title="Editor → Design">
    Found under **Settings → Editor → Design**, this group controls visual tooling layered on top of the code editor:

    - Tailwind CSS class scrubbing and controls
    - Design autocomplete suggestions
    - Design-specific diagnostics
    - Design blame annotations

    Live-page inspection in the Browser panel is separate — see **Visual Design** documentation.
  </Tab>
  <Tab title="Agents">
    Found under **Settings → Agents**, these options govern how the AI agent behaves:

    - **Auto-run** — allow the agent to run terminal commands without prompting
    - **Edit approval** — require you to accept each file change before it is applied
    - **Adversarial review** — have a second AI pass critique the agent's proposed edits
  </Tab>
</Tabs>

## How Settings Persist

Settings are saved locally on your machine and apply to all projects you open in Shape. If a project includes its own tooling configuration — for example a `.prettierrc` or `eslint.config.js` — that file takes precedence over the matching Shape setting for that project.

<Note>
  Reinstalling Shape does **not** remove your settings file. Your preferences survive updates and reinstalls.
</Note>

## Resetting a Setting

To restore a single setting to its default, select its default value from the control or clear the field. There is no "reset all settings" button — each preference must be restored individually.
