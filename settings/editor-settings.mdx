The Editor settings page controls everything about how the Monaco code editor looks and behaves. Open it with **Ctrl+,** and select **Editor** from the left-hand list.

## Font and Display

<Accordion title="Font family">
  Choose from a list of preset monospace fonts or type a custom font name installed on your system. The editor falls back to a system monospace font if the specified font is unavailable.
</Accordion>

<Accordion title="Font size">
  Sets the editor font size in pixels. Changes apply immediately across all open tabs.
</Accordion>

<Accordion title="Font ligatures">
  When enabled, glyph pairs like `=>`, `!=`, and `===` render as typographic ligatures. Requires a font that supports ligatures (e.g. Fira Code, Cascadia Code).
</Accordion>

<Accordion title="Minimap">
  Toggles the miniature code overview on the right edge of the editor. Useful for navigating long files at a glance. Toggle it quickly from the Command Palette (**Ctrl+Shift+P** → *Toggle Minimap*).
</Accordion>

<Accordion title="Line numbers">
  Show absolute line numbers, relative line numbers (useful for Vim-style navigation), or hide them entirely.
</Accordion>

<Accordion title="Render whitespace">
  Visualize spaces and tab characters in the editor gutter. Options include *none*, *boundary* (only at start/end of lines), *selection*, and *all*.
</Accordion>

<Accordion title="Line highlight">
  Highlights the line containing the cursor. Choose *line*, *gutter*, *all*, or *none*.
</Accordion>

<Accordion title="Bracket pair colorization">
  Assigns matching colors to opening and closing brackets, parentheses, and braces so you can visually trace nesting depth.
</Accordion>

<Accordion title="Indent guides and bracket guides">
  Indent guides draw vertical lines at each indentation level. Bracket guides extend those lines to the matching bracket pair.
</Accordion>

## Tabs and Indentation

| Setting | Description |
|---|---|
| **Tab size** | Number of spaces a tab character represents. |
| **Insert spaces** | When enabled, pressing Tab inserts spaces instead of a tab character. |
| **Detect indentation** | Shape reads the first few lines of a file and overrides your tab/space setting to match the file's existing style. |

## Editing Behavior

<Accordion title="Word wrap">
  - **Off** — lines extend horizontally; scroll to see them.
  - **On** — lines wrap at the viewport edge.
  - **Bounded** — lines wrap at a fixed column number you specify.

  Quick toggle: **Alt+Z**.
</Accordion>

<Accordion title="Cursor style">
  Choose between *line* (default thin caret), *block* (filled rectangle), or *underline*.
</Accordion>

<Accordion title="Smooth scrolling">
  Adds an easing animation when scrolling with the mouse wheel or keyboard. Disable for instant, snap-to-position scrolling.
</Accordion>

<Accordion title="Scroll beyond last line">
  Allows you to scroll past the final line so the last line of code can sit at the top of the viewport rather than the bottom.
</Accordion>

<Accordion title="Image preview">
  When enabled, hovering over an image file path in the editor shows an inline thumbnail.
</Accordion>

## Save and Formatting

<Accordion title="Auto save">
  | Option | Behavior |
  |---|---|
  | **Off** | Files save only when you press **Ctrl+S**. |
  | **After delay** | Saves automatically after a configurable delay (milliseconds). |
  | **On focus change** | Saves when you switch to another file or application window. |
</Accordion>

<Accordion title="Auto save delay">
  The number of milliseconds Shape waits after your last keystroke before auto-saving. Only applies when Auto save is set to *After delay*.
</Accordion>

<Accordion title="Format on save">
  Runs the document formatter whenever you save a file. When Prettier is enabled under **Settings → Features → ESLint & Prettier**, Prettier is used as the formatter. Otherwise the language server's built-in formatter runs.
</Accordion>

<Accordion title="Trim trailing whitespace">
  Removes spaces and tabs at the end of each line when the file is saved.
</Accordion>

<Accordion title="Insert final newline">
  Ensures files end with a newline character on save, which is required by many linters and POSIX tools.
</Accordion>

<Tip>
  Press **Alt+Shift+F** to format the current document at any time, or **Ctrl+K Ctrl+F** to format only the selected text.
</Tip>

## Editor → Design

The **Design** sub-section under Editor controls the visual coding layer built on top of Monaco. These settings are separate from the live-page Browser panel.

| Setting | Description |
|---|---|
| **Tailwind controls** | Enables inline scrubbing handles for Tailwind utility values (e.g. drag to change `p-4` to `p-6`). |
| **Design autocomplete** | Adds design-aware suggestions in the editor's completion list. |
| **Diagnostics** | Shows design-specific warnings and errors in the editor gutter and Problems panel. |
| **Design blame** | Annotates lines with information about their last design-related edit. |

<Note>
  Live-page inspect and the Apply-to-source workflow live in the Browser tab under **Visual Design**, not in Editor → Design.
</Note>
