Shape has two distinct sign-in flows that serve different purposes. Your **Shape account** unlocks cloud AI features like chat, code edits, and model selection. Your **GitHub sign-in** authenticates you against GitHub remote repositories for push, pull, and pull request workflows. The two are completely independent — you can use either, both, or neither depending on what you need.

<Note>
  Both sign-ins are entirely optional if you're working locally. You can open folders, edit files, run the terminal, and use the integrated Git client with local repositories without signing in to anything.
</Note>

## Shape account

A Shape account gives you access to all cloud AI capabilities in Shape, including the AI chat panel, agentic code edits, codebase indexing, model selection, and pull request summarisation. AI usage on paid models draws from your account credits.

### Sign in to your Shape account

<Steps>
  <Step title="Open the avatar menu">
    Click the **avatar icon** in the titlebar to open the account menu.
  </Step>
  <Step title="Start the sign-in flow">
    Click **Sign in to Shape**. Shape opens your default browser and takes you to the Shape authentication page.
  </Step>
  <Step title="Complete sign-in in your browser">
    Follow the prompts in the browser to create a new account or sign in to your existing one. Once you authorise the app, the browser confirms success and Shape updates automatically.
  </Step>
</Steps>

### Sign out of your Shape account

Open the **avatar menu** and click **Sign out**. This removes your Shape account session from the app. Your local files, settings, and Git configuration are not affected.

## GitHub sign-in

Signing in with GitHub authenticates Shape against your GitHub remote repositories. This lets you fetch, push, and pull over HTTPS without being prompted for credentials every time, and enables Git Manager features that interact with GitHub directly — such as browsing open pull requests and viewing Actions statuses.

GitHub sign-in is separate from your Shape account. You can have one without the other.

### Sign in with GitHub

<Steps>
  <Step title="Open the avatar menu">
    Click the **avatar icon** in the titlebar.
  </Step>
  <Step title="Start GitHub authorisation">
    Click **Sign in with GitHub**. Shape opens your default browser and redirects you to GitHub's authorisation page.
  </Step>
  <Step title="Authorise Shape on GitHub">
    Review the requested permissions and click **Authorize** on the GitHub page. Once authorised, the browser confirms success and Shape stores your GitHub credentials securely.
  </Step>
</Steps>

### Sign out of GitHub

Open the **avatar menu** and click **Sign out** next to the GitHub entry. This clears your GitHub remote authentication only — your Shape account and all local data remain untouched.

## When do you need each account?

| Feature | Shape account | GitHub sign-in |
|---|:---:|:---:|
| AI chat and agentic edits | ✅ Required | — |
| Model selection and credits | ✅ Required | — |
| Codebase indexing | ✅ Required | — |
| Pull request summarisation | ✅ Required | — |
| Push / pull to GitHub remotes | — | ✅ Recommended |
| Git Manager pull request list | — | ✅ Required |
| GitHub Actions status | — | ✅ Required |
| Local editing, terminal, Git | Optional | Optional |
