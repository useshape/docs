This guide takes you through Shape's essential workflows end-to-end. By the time you finish, you'll have a project open, know the shortcuts that matter most, and have sent your first AI chat message — all without leaving the app.

<Tip>
  Press **Ctrl+Shift+P** to open the Command Palette at any time. It searches every action, setting, and command in Shape, making it the fastest way to find anything you haven't memorised yet.
</Tip>

## Welcome screen

When you launch Shape, the welcome screen gives you four quick actions:

- **Open Project** — open a local folder on your machine
- **Open Terminal** — launch the integrated terminal immediately
- **Open AI Chat** — jump straight into an AI conversation
- **Clone Repository** — clone a remote Git repo by URL

You can reopen the welcome screen at any time from **Help → Welcome**.

<Steps>
  <Step title="Open a project">
    Choose how you want to start:

    <Tabs>
      <Tab title="Open a local folder">
        Go to **File → Open Folder** or press **Ctrl+K Ctrl+O**, then navigate to your project directory and select it.
      </Tab>
      <Tab title="Clone a repository">
        Click **Clone Repository** on the welcome screen, paste the Git URL of the repo you want, choose a local destination, and Shape will clone and open it automatically.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Learn the essential shortcuts">
    These are the keyboard shortcuts you'll use constantly in Shape:

    | Action | Shortcut |
    |---|---|
    | Command Palette | **Ctrl+Shift+P** |
    | Quick open file | **Ctrl+P** |
    | Find in project | **Ctrl+Shift+F** |
    | Toggle terminal | **Ctrl+`** |
    | Open settings | **Ctrl+,** |
    | Toggle AI chat | **Ctrl+L** |

    <Tip>
      When in doubt, open the Command Palette with **Ctrl+Shift+P** and type what you want to do. Shape will find the matching command even if you don't know the exact name.
    </Tip>
  </Step>
  <Step title="Configure the basics">
    Open **Settings** with **Ctrl+,** and adjust the following to match your preferences:

    - **Editor** — font family, font size, format on save, and tab size
    - **Editor → Design** — enable Tailwind CSS integration for live class previews
    - **Agents** — select your preferred AI model, configure auto-run behaviour, and set up MCP connections
  </Step>
  <Step title="Try AI chat">
    Press **Ctrl+L** to open the AI chat panel, then type your first message — a question, a task, or a description of what you want to build.

    Use `@` mentions to give the AI precise context:

    - `@filename` — reference a specific file
    - `@folder` — include an entire directory
    - `@codebase` — let the agent search your whole project
    - `@selection` — send the text you currently have highlighted

    When you switch to **Code mode**, the agent can search your codebase, edit files, and run checks autonomously. After it finishes, review each change and click **Keep** to accept or **Undo** to revert.
  </Step>
  <Step title="Preview your UI and manage Git">
    Shape combines live preview and version control in the same window:

    - **Live preview** — click the Chrome icon in the activity bar to open the browser panel. Enter your local dev server URL (e.g., `http://localhost:3000`) and enable design mode to see your UI update as you edit.
    - **Git** — open the Git Manager from the activity bar. Stage individual hunks directly from the diff view, write your commit message, and push your changes or open a pull request without leaving Shape.
  </Step>
</Steps>
