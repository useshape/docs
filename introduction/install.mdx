# Get started with Shape

Shape is a Windows app for working on your code. Open a folder, edit files, use Git and the terminal, preview your site, and chat with an agent that can work in your project.

[Download Shape](https://useshape.org/download)

## Get started in three steps

Download Shape for Windows and follow the installation steps.

Open Shape and sign in.

Open the folder that contains your project.

Once your files appear, you are ready to work.

Choose how you want to work, then start with your project.

## Chat with an agent

Pick a mode and a model, then describe what you want to do.

Use `@` to attach a file.

Use `/` to run a saved prompt from Workflows.

Select **Stop** to cancel a task.

When the agent makes changes, review the diff and keep or undo them.

## Modes

Ask questions without changing your files.

Make changes to your project.

Save a plan in the project. The checklist appears in the plan view, then you build from there.

Work on your UI in chat.

Find an issue and make a small fix.

A manager assigns work to other agents shown above the input. The agents can communicate with each other. The manager only assigns work.

## Plugins and workflows

Plugins connect services such as GitHub, Slack, and Linear.

MCP adds extra local tools through **Configure MCP**.

Workflows are saved prompts. Type `/` in chat to run one.

## Git and GitHub

Open Git with `Ctrl+Shift+G`.

GitHub login is separate from Shape. It is used for pull requests, issues, and Actions.

Shape asks you to confirm a new pull request before publishing it.

In a diff:

- `Ctrl+Y` stages the hunk.
- `Ctrl+Shift+Y` unstages the hunk.
- Outside a diff, `Ctrl+Y` is redo.

## Next steps

Open a project folder, choose a mode, and start working.
