Shape is a native Windows desktop IDE that brings together agentic AI chat, a full Monaco code editor, live design preview, and built-in Git management in one cohesive app. Whether you're writing code, iterating on a UI, or letting AI handle a refactor end-to-end, Shape keeps every tool within reach so you stay in flow from first keystroke to final commit.

## Get up and running

<Steps>
  <Step title="Download and install Shape">
    Visit [useshape.org/download](https://useshape.org/download), run the installer, and launch Shape from your Start menu. The whole process takes under five minutes.
  </Step>
  <Step title="Open a project">
    Choose **File → Open Folder** to open an existing project, or use **Clone Repository** on the welcome screen to pull down a remote repo and get straight to work.
  </Step>
  <Step title="Try AI chat">
    Press **Ctrl+L** to open the AI chat panel. Type a question or a task, use `@` mentions to reference specific files or your entire codebase, and watch Shape's agent search, edit, and verify changes for you.
  </Step>
  <Step title="Explore Git">
    Click the Git icon in the activity bar to open the Git Manager. Stage hunks from the diff view, write a commit message, and push — or open a pull request directly from within Shape.
  </Step>
</Steps>
