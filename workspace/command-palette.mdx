The command palette is the fastest way to trigger any action in Shape — whether it's a menu item, an editor command, or something that has no button at all. If you can only learn one shortcut in Shape, make it this one.

## Opening the Command Palette

Press **Ctrl+Shift+P** or go to **View → Command Palette**. You can also open it from the activity bar's bottom terminal-icon button.

- Start typing to filter the list immediately using fuzzy matching on both the command label and its shortcut.
- Use the **arrow keys** to navigate results.
- Press **Enter** to run the highlighted command.
- Press **Escape** to close without running anything.

Keyboard shortcuts are shown on the right side of each result so you can learn them as you go.

## Modes and Prefixes

The command palette doubles as a multi-mode launcher. Change the prefix character to switch modes:

| Prefix | Mode | Shortcut |
|---|---|---|
| `>` | **Command list** — all workbench and editor commands | **Ctrl+Shift+P** |
| *(empty)* | **Go to File** — open any file by name | **Ctrl+P** |
| `:` | **Go to Line** — jump to a line or line:column | **Ctrl+G** |
| `#` | **Workspace Symbols** — find functions, classes, variables | **Ctrl+T** |

### Go to File (Ctrl+P)

Press **Ctrl+P** to jump straight into file search. Type part of a filename, select the result, and press **Enter** to open it. This is a separate shortcut from the full command list — use it when you know what file you want.

### Go to Line (Ctrl+G)

Press **Ctrl+G** and type a line number to jump there instantly. Append a column number with a colon to land on the exact character — for example, `42:8` moves the cursor to line 42, column 8.

### Workspace Symbols (Ctrl+T)

Press **Ctrl+T** to search for functions, classes, and variables across your entire project. Results depend on the language server (LSP) available for your project's language.

<Note>
  Workspace symbol indexing runs in the background after you open a project. Results improve as indexing completes, especially in large codebases.
</Note>

## Palette-Only Commands

Some Shape features have no button or menu item — the command palette is the only way to reach them:

| Command | What it does |
|---|---|
| **Chat: Show History** | Browse past AI conversations and reopen any of them |
| **View: Show Problems** | Open the Problems tab in the bottom panel |
| **View: Show Output** | Open the Output tab in the bottom panel |
| **Editor: Toggle Minimap** | Show or hide the minimap in the editor gutter |
| **Change Language Mode…** | Override the language for the current file; Shape remembers the setting for that file path |

<Tip>
  **Quick Fix** (**Ctrl+.**) isn't in the palette, but you can search for fix-related commands there. Use **Ctrl+.** directly on a highlighted error or warning in the editor for the fastest results.
</Tip>

## Browsing AI Chat History

<Steps>
  <Step title="Open the command palette">
    Press **Ctrl+Shift+P**.
  </Step>
  <Step title="Run Chat: Show History">
    Type `chat history` and select **Chat: Show History** from the results.
  </Step>
  <Step title="Select a conversation">
    Browse the list of past conversations and press **Enter** on any entry to reopen it in the AI Chat sidebar.
  </Step>
</Steps>

## Tips for Faster Navigation

<Accordion title="Fuzzy matching">
  You don't need to type the exact command name. Shape matches characters in order anywhere in the label — typing `tgz` will find **Editor: Toggle Zen Mode**, for example. Shorter queries often surface what you need.
</Accordion>

<Accordion title="Changing the language mode for a file">
  Open the command palette, run **Change Language Mode…**, and pick the language from the list. Shape stores this override for that specific file path so it persists across sessions.
</Accordion>

<Accordion title="Keyboard shortcut discovery">
  The shortcut shown next to each command in the palette is always up to date. Browse the list to discover shortcuts for commands you use often, then start using them directly.
</Accordion>
