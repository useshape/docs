The AI Chat panel is a full agentic assistant that lives in Shape's right sidebar. In a single conversation thread, it can search your repository, read and edit source files, run terminal commands, and report back — all without you switching context.

## Open and Resize the Chat Panel

| Action | How |
|---|---|
| Toggle chat open/closed | Click **AI Chat** in the titlebar, or go to **View → AI Chat**, or press `Ctrl+L` |
| Resize the panel | Drag the divider between the editor and the chat sidebar |

## Sign In

Cloud AI models require a Shape account. Sign in through the prompt that appears when you first try to send a message. Local file navigation and editing in the IDE does not require sign-in.

## Send Your First Message

<Steps>
  <Step title="Type your message">
    Click in the chat input and write your question or instruction.
  </Step>
  <Step title="Choose a mode">
    Select a mode from the dropdown — **Ask** for read-only questions, **Code** to let the agent implement changes. See [Chat Modes](/ai/chat-modes) for all options.
  </Step>
  <Step title="Choose a model (optional)">
    Pick a specific model from the model selector, or leave it on **Auto** to let Shape choose.
  </Step>
  <Step title="Send">
    Press `Enter` to send. Use `Shift+Enter` to add a new line without sending.
  </Step>
</Steps>

Shape automatically attaches workspace context to every message — open files, project layout, and diagnostics — so you don't have to copy-paste code to get relevant answers.

## Use @Mentions to Target Context

Type `@` in the chat input to pin specific context to your message:

| Mention | What it attaches |
|---|---|
| `@filename` | A specific file from your project |
| `@foldername` | All files inside a folder |
| `@codebase` | A semantic search across the entire project |
| `@selection` | The text currently selected in the editor |

## What the Agent Does in Code Mode

When you use **Code** mode, the agent works through a series of steps and shows its progress in the thread:

- **Searches and reads files** to understand the codebase before making changes
- **Edits files** — each edit appears as a step with `+/-` line counts, and you can review the diff
- **Runs terminal commands**, tests, and linters
- **Calls finish** when the task is complete, summarizing what changed

Tool activity is grouped and collapsed into a summary so the thread stays readable.

## Attach Images and Files

Use the attachment control in the chat input to upload screenshots, design references, or specific files. This is useful for sharing a UI mockup and asking the agent to implement it, or pasting an error screenshot when logs aren't available.

## Control Terminal Commands

By default, Shape uses **Auto (safe commands)** mode: common safe commands run automatically, and destructive commands (like `git reset` or `git clean`) always prompt you first. To review every command before it runs, switch to **Ask every time** in **Settings → Agents**.

## Stop a Response

Click **Stop** at any time while the agent is streaming a response. Partial output — including any edits already written — stays in place.

## Chat History

Chat history is stored per project. To reopen a previous conversation, open the Command Palette and run **Chat: Show History**.

<Tip>
Start with **Ask** mode when you're exploring or learning a codebase — it can't modify files, so there's nothing to accidentally undo.
</Tip>
