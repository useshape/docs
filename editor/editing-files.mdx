Shape's editor is built on Monaco — the same engine that powers VS Code — giving you syntax highlighting, multi-cursor editing, and language-aware features in a native desktop experience. Everything from quick file navigation to Prettier formatting is available without extensions or configuration.

## Opening Files

Use any of the following to open files in the editor:

| Action | Shortcut |
|---|---|
| Open File | `Ctrl+O` |
| Open Folder | `Ctrl+K` `Ctrl+O` |
| New File | `Ctrl+N` |
| Quick Open (by name) | `Ctrl+P` |

**New Text File** (from the File menu) creates an untitled buffer that appears in the Explorer once you save it. **New Scratch File** creates a temporary buffer that is never written to disk — useful for quick notes or throwaway snippets.

## Saving and Closing Files

<Tip>
The Explorer badge and a dot on the tab both indicate unsaved changes. Save early and often to keep the badge clear.
</Tip>

| Action | Shortcut |
|---|---|
| Save | `Ctrl+S` |
| Save As | `Ctrl+Shift+S` |
| Save All | `Ctrl+K S` |
| Close Tab | `Ctrl+W` |
| Close All Tabs | `Ctrl+K E` |

Tabs with unsaved changes show a dot (●) in place of the close icon. The Explorer also shows a badge with the count of unsaved files across the project.

| Copy | `Ctrl+C` |

## Multi-Cursor Editing

Multi-cursor lets you edit multiple locations in a file simultaneously. Each cursor acts independently, so typing, deleting, and pasting all apply to every cursor at once.

| Action | Shortcut |
|---|---|
| Add cursor at click location | `Alt+Click` |
| Add cursor above | `Ctrl+Alt+↑` |
| Add cursor below | `Ctrl+Alt+↓` |
| Select all occurrences of selection | `Ctrl+Shift+L` |

<Tip>
Use `Ctrl+Shift+L` to rename a variable across the entire file instantly — select the name, press the shortcut, then type the new name.
</Tip>

## Line Operations

These shortcuts work on the current line without requiring a selection:

| Action | Shortcut |
|---|---|
| Move line up | `Alt+↑` |
| Move line down | `Alt+↓` |
| Duplicate line below | `Shift+Alt+↓` |
| Toggle line comment | `Ctrl+/` |
| Toggle block comment | `Shift+Alt+A` |
| Indent | `Ctrl+]` |
| Outdent | `Ctrl+[` |

## Formatting Code

Shape uses **Prettier** for formatting when a `.prettierrc` or `prettier.config.js` is present in your project. Enable it under **Settings → Features → ESLint & Prettier**.

| Action | Shortcut |
|---|---|
| Format Document | `Alt+Shift+F` |
| Format Selection | `Ctrl+K` `Ctrl+F` |

You can also trigger **Edit → Format Document** from the menu bar. To format automatically on every save, enable **Format on Save** in the same settings panel.

## Navigating Code

<Accordion title="Navigation shortcuts">

| Action | Shortcut |
|---|---|
| Go to Line | `Ctrl+G` |
| Go to Definition | `F12` |
| Go to Matching Bracket | `Ctrl+Shift+\` |
| Navigate Back | `Alt+Left` |
| Navigate Forward | `Alt+Right` |

</Accordion>

**Go to Definition** (`F12`) jumps to where a symbol is declared — across files if a language server is active. Use **Alt+Left** to jump back to where you were.

## Word Wrap

Toggle word wrap with **View → Word Wrap** or press `Alt+Z`. Wrapped lines display a visual continuation indicator but do not insert actual line breaks in the file.

## Auto-Save

To save files automatically, go to **Settings → Editor** and choose an auto-save trigger:

- **After delay** — saves a configurable number of milliseconds after your last keystroke.
- **On focus change** — saves when you click away from the editor pane.

<Note>
Auto-save does not affect the dirty-tab dot until the file is written. If you use Format on Save, auto-save triggers formatting as well.
</Note>
