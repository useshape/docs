Shape extends the Monaco editor with design-aware tooling built specifically for web UI work. Inline controls, a color picker, number scrubbing, and accessibility diagnostics live directly in the editor so you can iterate on layouts and styles without switching to a separate design tool.

## Inline Tailwind Controls

When your cursor is inside a `className` string, Shape displays a floating panel of visual controls anchored to that token. Each control maps directly to a Tailwind utility class and updates the value in place as you adjust it.

| Control | What it adjusts |
|---|---|
| **Flex / Grid** | Direction, wrap, justify-content, align-items |
| **Gap** | Column gap and row gap |
| **Padding** | Each side independently |
| **Radius** | Per-corner with Tailwind corner stops |
| **Color picker** | Tailwind palette + project CSS variables |

```tsx
// Cursor inside className — the floating panel appears
<div className="flex flex-col gap-4 p-6 rounded-lg bg-blue-500">
  {children}
</div>
```

The panel closes when you move the cursor outside the `className` value.

## Number Scrubbing

Scrubbing lets you adjust numeric values in Tailwind classes or CSS properties by dragging or scrolling rather than typing.

<Steps>
  <Step title="Position your cursor">
    Place the cursor on or near a numeric token — for example `gap-4`, `p-[24px]`, or a CSS property like `padding: 16px`.
  </Step>
  <Step title="Scrub the value">
    Hold `Alt` and drag left or right over the number to decrease or increase it. Alternatively, hover over the underlined number and use the scroll wheel. Hold `Shift` while scrolling to step by 1px increments.
  </Step>
  <Step title="Snap to scale">
    Tailwind spacing values snap to the spacing scale automatically (0, 0.5, 1, 1.5, 2 … 96). Arbitrary values in brackets increment by 1px.
  </Step>
</Steps>

<Tip>
Toggle number scrubbing, underlines, cursor-bind, and wheel-on-inputs under **Settings → Editor → Design** if you prefer to adjust numbers by keyboard only.
</Tip>

## Design Autocomplete

Shape ranks Tailwind utility suggestions using signals from your project to surface the most relevant completions first:

- **Project frequency** — classes already used in your codebase rank higher.
- **Sibling context** — if adjacent elements use `flex`, flex utilities appear at the top.
- **Fuzzy matching** — type partial class names and Shape resolves the closest match.
- **Spacing scale awareness** — only valid scale steps appear in spacing completions.

Enable or disable Design Autocomplete under **Settings → Editor → Design → Design Autocomplete**.

## Design Blame

Hover over any Tailwind token to see a plain-language git blame blurb describing the last change to that value — who changed it and when, in readable prose rather than raw git output.

```tsx
// Hover over "bg-blue-500"
// ↳ "Changed by alex 2 days ago in feat/redesign-header"
```

Disable this under **Settings → Editor → Design → Design Blame Hover**.

## Spacing Scale Refactor

To update a spacing value consistently across an entire file:

<Steps>
  <Step title="Right-click the value">
    Right-click any Tailwind spacing number (e.g., the `4` in `gap-4`).
  </Step>
  <Step title="Run the refactor">
    Select **Refactor spacing scale** from the context menu.
  </Step>
  <Step title="Confirm the replacement">
    Shape replaces all matching spacing values in the file with the new value you choose.
  </Step>
</Steps>

## Color Picker

The inline color picker activates when your cursor is on a color-related Tailwind class or a CSS color property. It reads both the Tailwind palette and your project's CSS variables.

- Select a swatch from the Tailwind palette to insert the corresponding class (e.g., `text-emerald-600`).
- Select a CSS variable to insert a `var(--your-variable)` reference at the cursor.

```css
/* CSS variable defined in your project */
:root {
  --brand-primary: #6366f1;
}
```

```tsx
{/* Color picker offers --brand-primary alongside Tailwind swatches */}
<button className="bg-[--brand-primary]">Get started</button>
```

## Accessibility Diagnostics

Shape checks color contrast in JSX, TSX, and CSS files and surfaces violations as squiggles in the editor and entries in the Problems panel (`Ctrl+Shift+M`).

Configure accessibility checking under **Settings → Editor → Design**:

| Setting | Options |
|---|---|
| **WCAG Contrast Warnings** | On / Off |
| **Compliance Level** | AA (4.5:1 normal text, 3:1 large) / AAA (7:1 normal text) |

<Warning>
WCAG AAA compliance is stricter and will flag more contrast combinations. Start with AA and upgrade to AAA when your project requires it.
</Warning>
