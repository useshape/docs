Shape includes a built-in Markdown renderer so you can read formatted output alongside your source without switching to an external tool. Open any `.md` or `.mdx` file and toggle between three display modes directly from the tab bar.

## Opening a Markdown File

Open a Markdown file from the Explorer panel or by pressing `Ctrl+P` and typing the filename. Shape detects `.md` and `.mdx` extensions automatically and activates Markdown syntax highlighting in source mode.

<Note>
If a file is not detected as Markdown, open the Command Palette (`Ctrl+Shift+P`) and run **Change Language Mode**, then select **Markdown**.
</Note>

## Preview Modes

The tab bar for Markdown files shows three mode buttons:

<CardGroup cols={3}>
  <Card title="Source" icon="code">
    Displays the raw Markdown in the Monaco editor with full syntax highlighting. All editing features — multi-cursor, IntelliSense, Find — are available.
  </Card>
  <Card title="Split" icon="table-columns">
    Shows the Monaco editor on the left and the rendered preview on the right simultaneously. Edit on the left and confirm the layout on the right.
  </Card>
  <Card title="Preview" icon="eye">
    Full-width rendered output. Use this when you want to read the document without distraction.
  </Card>
</CardGroup>

## What the Preview Renders

Shape's preview handles the full range of standard Markdown:

- Headings, paragraphs, and lists (ordered and unordered)
- Links and images — relative paths resolve from the file's location on disk
- Fenced code blocks with syntax highlighting
- Blockquotes and horizontal rules
- Inline formatting: **bold**, *italic*, `code`, ~~strikethrough~~

<Note>
Complex MDX component syntax (custom React components, JSX expressions) may not render identically to your production site. The preview targets common Markdown and basic MDX, not full MDX execution.
</Note>

## Editing in Split Mode

<Steps>
  <Step title="Switch to Split mode">
    Click the **Split** button on the tab bar to open the editor and preview side by side.
  </Step>
  <Step title="Edit on the left">
    Type in the editor pane as normal. The preview updates automatically as you make changes.
  </Step>
  <Step title="Save to persist">
    Press `Ctrl+S` to save. The preview reflects the saved file, but it also updates on unsaved content changes so you see feedback immediately.
  </Step>
</Steps>

## Tips

<Tip>
Combine Split mode with Zen Mode (`Ctrl+K Z`) for a focused writing environment — you get the full editor and rendered preview with all other UI hidden.
</Tip>

- Use **Bookmarks** alongside the preview to mark key sections and jump between them while writing long documents.
- Switch to **Preview** mode when reviewing a finished draft — the full-width view gives you the most accurate sense of the final layout.
