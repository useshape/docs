Shape provides first-class editing support for the languages you work with every day. Syntax highlighting covers over 40 languages out of the box, while built-in Prettier, ESLint, and language servers give TypeScript, CSS, HTML, JSON, and Python projects accurate formatting, linting, and IntelliSense without any plugin installation.

## Changing the Language Mode

Shape detects the language from the file extension automatically. To override it, open the Command Palette (`Ctrl+Shift+P`) and run **Change Language Mode**, then select the language you want. This is useful for files with non-standard extensions or for scratch buffers.

## Prettier

Prettier formats JavaScript, TypeScript, JSON, CSS, SCSS, HTML, and Markdown files on demand or automatically on save.

<Steps>
  <Step title="Enable Prettier">
    Go to **Settings → Features → ESLint & Prettier** and turn on Prettier.
  </Step>
  <Step title="Add a project config (optional)">
    Place a `.prettierrc` or `prettier.config.js` file at your project root. Shape reads it automatically and applies your formatting rules.
  </Step>
  <Step title="Format a file">
    Press `Alt+Shift+F` to format the entire document, or `Ctrl+K` `Ctrl+F` to format only the selected text.
  </Step>
  <Step title="Enable Format on Save (optional)">
    Turn on **Format on Save** in the same settings panel to format every file automatically when you press `Ctrl+S`.
  </Step>
</Steps>

```json
// .prettierrc
{
  "semi": false,
  "singleQuote": true,
  "tabWidth": 2,
  "trailingComma": "es5"
}
```

## ESLint

ESLint surfaces rule violations as squiggles in the editor and entries in the Problems panel (`Ctrl+Shift+M`).

**Supported file types:** `.js`, `.jsx`, `.ts`, `.tsx`, `.mjs`, `.cjs`, `.vue`, `.svelte`

Enable ESLint under **Settings → Features → ESLint & Prettier**. Turn on **Fix on Save** in the same panel to automatically apply safe auto-fixes whenever you save a file.

<Note>
Shape uses your project's own `eslint.config.js` or `.eslintrc` file. If no config is present, ESLint runs with no rules applied and will not report issues.
</Note>

## Language Servers (IntelliSense)

Language servers provide completions, go-to-definition, hover documentation, and rename-symbol. Toggle each one under **Settings → Features → Language Servers**.

| Language Server | Capabilities |
|---|---|
| **TypeScript** | Completions, go-to-definition, find references, rename, refactor hints (`.ts`, `.tsx`, `.js`, `.jsx`) |
| **HTML** | Tag and attribute completions, linked CSS/JS editing |
| **CSS** | Property and value completions, selector resolution (`.css`, `.scss`, `.less`) |
| **JSON** | Schema-aware completions and validation |
| **Python (Pyright)** | Type-aware completions, go-to-definition, diagnostics |
| **GraphQL** | Query completions against schema |
| **Markdown** | Link completions, heading navigation (remark language service) |
| **Tailwind CSS** | Utility class completions in `className` and `class` attributes |
| **Vue / Svelte** | Component and prop completions inside `.vue` and `.svelte` files when those frameworks are detected |

## Emmet

Emmet expands abbreviations into full HTML and CSS markup in HTML, CSS/SCSS/Less, and JSX/TSX files. Type an abbreviation and press `Tab` to expand it.

```html
<!-- Type: ul>li.item*3  then press Tab -->
<ul>
  <li class="item"></li>
  <li class="item"></li>
  <li class="item"></li>
</ul>
```

Toggle Emmet under **Settings → Features → Language Servers**.

## Design Tooling

Shape extends the editor with design-aware features for web UI work:

- **Tailwind class completions** — ranked by project frequency with spacing scale awareness.
- **Inline Tailwind controls** — visual panels for flex, gap, padding, radius, and color when your cursor is inside a `className` string.
- **CSS variable IntelliSense** — completes project-defined CSS variables in class attributes and stylesheets.
- **Accessibility diagnostics** — contrast checks for JSX/TSX/CSS with WCAG AA/AAA compliance levels configurable in **Settings → Editor → Design**.

See [Design Tools](./design-tools) for the full reference.
