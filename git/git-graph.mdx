Shape's Git Graph sidebar renders your repository's full commit history as a lane diagram, giving you a visual map of every branch, merge, and commit. Use it to understand how your codebase evolved, pinpoint when a change was introduced, or compare an older commit against your current working tree.

## Open Git Graph

- Click the **commit icon** on the activity bar (left sidebar)
- Go to **View → Git Graph**

Shape loads the commit history for the currently open Git repository. For very large repositories, the graph virtualizes as you scroll — only visible rows are rendered, so performance stays consistent regardless of history length.

<Note>
For a larger graph view alongside pull requests and CI checks, open **Git Manager** via **Window → Git Manager** or by clicking the Shape logo in the Git Graph sidebar header.
</Note>

## Read the Graph

Each row in the graph represents a single commit. The columns are:

| Column | Description |
|--------|-------------|
| **Lane lines** | Branch and merge topology — diverging lines show branches, converging lines show merges |
| **Message** | Commit subject line. Click `@mentions` to view the referenced GitHub profile |
| **Author** | The commit author's name or avatar |
| **Time** | Relative timestamp (e.g., "3 days ago") |

### Expand a commit

Click a commit row to expand it and see the list of files changed in that commit. Click any file in the expanded view to open a diff tab for that specific change.

### Display options

Open **Git Settings** to toggle:
- **Author avatars** — show profile pictures next to commit authors
- **Show all branches** — include commits from branches not currently checked out (on by default)

## Commit Actions

Right-click any commit row to access these actions:

<CardGroup cols={2}>
  <Card title="Checkout" icon="code-branch">
    Check out the selected commit, entering a detached HEAD state, or check out a branch tip.
  </Card>
  <Card title="Compare with Working Tree" icon="code-compare">
    Diff the commit against your current uncommitted state to see what has changed since then.
  </Card>
  <Card title="View File Changes" icon="file-magnifying-glass">
    Open diff tabs for every file changed in that commit.
  </Card>
  <Card title="Copy Commit Hash" icon="copy">
    Copy the full SHA to your clipboard for use in terminal commands or pull request references.
  </Card>
</CardGroup>

## Search and Filter

Type in the **search field** at the top of the Git Graph panel to filter commits by **message** or **author name**. Only matching commits are shown. Clear the search field to return to the full history.

## Refresh the Graph

If you run Git operations outside of Shape — in a terminal or another tool — click **Refresh** in the Git Graph toolbar to reload the commit history and reflect the latest state.
