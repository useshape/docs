Shape's Source Control panel is a full Git client built directly into the IDE. Stage individual files or specific lines of code, write commits with AI-generated suggestions, and push to your remote — all without switching to an external tool.

## Open Source Control

You can open the Source Control panel in three ways:

- Click the **branch icon** on the activity bar (left sidebar)
- Press **Ctrl+Shift+G** or go to **View → Source Control**
- Click the **branch indicator** in the status bar at the bottom of the window

<Note>
For pull requests, GitHub Actions, and CI checks, open the **Git Manager** instead — go to **Window → Git Manager** or click the Shape logo in the Source Control sidebar header.
</Note>

## View Changed Files

The **Changes** section lists every modified, added, or deleted file in your working tree. Click any file to open a diff tab showing exactly what changed.

| Icon | Meaning |
|------|---------|
| `M`  | Modified |
| `A`  | Added (untracked) |
| `D`  | Deleted |

## Stage and Unstage Changes

### Stage entire files

- **Stage a file** — click the **`+` icon** next to the file
- **Stage all files** — click the **`+` icon** on the **Changes** section header
- **Unstage a file** — click the **`−` icon** next to a staged file
- **Discard changes** — right-click a file and select **Discard Changes**

### Stage individual hunks or lines

For surgical staging, open a file from the Changes list to view its diff. A floating toolbar appears on each hunk:

- **Working Tree (unstaged)** — press **Ctrl+Y** to stage the hunk, or **Restore** to discard it
- **Index (staged)** — press **Ctrl+Shift+Y** to unstage the hunk

To stage or restore only specific lines, select those lines in the diff before using the toolbar actions.

## Write and Commit

<Steps>
  <Step title="Stage your changes">
    Use the `+` icons or hunk toolbar to stage the files and lines you want to include in this commit.
  </Step>
  <Step title="Enter a commit message">
    Type a short summary in the commit message field at the top of the Source Control panel.
  </Step>
  <Step title="Add an optional description">
    Press **Tab** or click the description field below the message to add a longer explanation of the change.
  </Step>
  <Step title="Commit">
    Click **Commit** or press **Ctrl+Enter** to create the commit.
  </Step>
</Steps>

<Tip>
Enable **Confirm Before Commit** in Git Settings to show a confirmation dialog before each commit — useful when you want to double-check staged files before finalizing.
</Tip>

### AI commit message suggestions

Click the **sparkle icon** next to the commit message field to let Shape's AI generate a suggested title and description based on your staged diff. You can accept, edit, or ignore the suggestion.

## Sync with Remote

The Source Control toolbar provides four sync actions:

| Action | What it does |
|--------|-------------|
| **Pull** | Fetches and merges changes from the remote branch |
| **Push** | Uploads your local commits to the remote |
| **Sync** | Pulls first, then pushes |
| **Refresh** | Re-reads the local repo state |

<Tip>
Sign in to GitHub from the avatar menu in the titlebar to push and pull without credential prompts. See [GitHub Sign-In](/git/github-sign-in) for setup steps.
</Tip>

## Initialize a New Repository

If the folder you have open is not yet a Git repository, the Source Control panel shows an **Initialize Repository** action. Click it to run `git init` and start tracking changes immediately.

## Status Bar

The status bar at the bottom of the window always shows the **current branch name** along with **ahead/behind counts** (e.g., `↑2 ↓1`) after a fetch. Click the branch indicator at any time to open Source Control.
